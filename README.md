# Калькулятор

Веб-калькулятор в стиле мобильных приложений: круглые кнопки, живой предпросмотр результата, история вычислений и тёмная/светлая тема. Написан на чистом HTML, CSS и JavaScript — без библиотек и сборщиков.

## Демо

[Открыть на GitHub Pages]()

## Возможности

- Четыре арифметические операции: `+`, `−`, `×`, `÷`
- Скобки, включая вложенные
- Автоматическое закрытие скобок при нажатии `=`
- Неявное умножение: `2(3+4)` → `2×(3+4)`
- Процент `%` с учётом контекста:
  - `200 × 10% = 20`
  - `50 + 10% = 55`
  - `50% = 0.5`
- Живой предпросмотр результата прямо во время ввода
- Обработка деления на ноль
- Округление до 12 значащих цифр — без артефактов типа `0.30000000000000004`
- История последних 20 вычислений в `localStorage`
- Клик по записи истории подставляет результат в текущее выражение
- Тёмная и светлая тема с переключателем
- Автоматическая подстройка под системную тему
- Сохранение выбранной темы и истории между сессиями
- Адаптивная вёрстка под мобильные устройства
- Поддержка клавиатуры (Tab, Enter, пробел) — доступность

## Технологии

- **HTML5** — семантическая разметка, `data-*` атрибуты
- **CSS3** — CSS-переменные, Grid, Flexbox, `aspect-ratio`, `prefers-color-scheme`, плавные transition
- **JavaScript (ES6+)** — без фреймворков:
  - Делегирование событий
  - Объект `state` как единый источник правды
  - Рекурсивный парсер выражений (метод рекурсивного спуска)
  - `localStorage` для истории и темы
- **Git / GitHub** — версионирование, GitHub Pages для хостинга

## Как это устроено

### Парсер выражений

Вычисление выражений **не через `eval()`** — это дыра в безопасности и непредсказуемое поведение. Вместо этого написан маленький парсер методом рекурсивного спуска:

```
expression = term (("+" | "-") term)*
term       = factor (("*" | "/") factor)*
factor     = number | "(" expression ")" | "-" factor
```

Парсер состоит из трёх частей:

1. **`tokenize()`** — превращает строку `"2×(3+4)"` в массив токенов
2. **`Parser`** — рекурсивно вычисляет значение с правильным приоритетом операций
3. **`evaluate()`** — обёртка с обработкой ошибок (возвращает `null` вместо исключения)

Преимущества: безопасно, предсказуемо, легко расширяется (например, для `√`, `sin`, `π`).

### Состояние

Всё состояние — в одном объекте:

```js
const state = {
  expression: "0",        // вся строка выражения
  justEvaluated: false,   // только что нажали "="
};
```

Никаких `previousInput` + `operator` + `currentInput`. Одна строка — один источник правды. Отсюда живой предпросмотр получается тривиально: просто вызвать `evaluate(state.expression)`.

### Делегирование событий

Один `addEventListener` на `document` ловит клики по всем кнопкам. Кнопки размечены `data-*` атрибутами:

```html
<button data-number="7">7</button>
<button data-operator="+">+</button>
<button data-action="equals">=</button>
```

Никаких 20 отдельных обработчиков и id на каждую кнопку.
